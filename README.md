# MobiliaNew — Inteligência Imobiliária e de Construção (Radar de Obras & Leilões)

Protótipo interativo de validação comercial e apresentação estratégica do ecossistema **MobiliaNew**.

## Módulos Inclusos no Protótipo (`index.html`)
1. **Landing Page & Isca de Topo de Funil:** Auditoria interativa gratuita por cidade e nicho (Marmoraria, Móveis Planejados, Energia Solar, Esquadrias e Investidores).
2. **Radar de Obras & Alvarás (B2B):** Painel de prospecção ativa com Score IA (0-100), validação cruzada DoubleCheck™ (Diário Oficial + Receita Federal + CAU/CREA) e gerador de scripts de abordagem para WhatsApp.
3. **Radar de Oportunidades Imobiliárias (Leilões):** Leitura de editais e matrículas por IA com simulador interativo de margem líquida e custo de reforma.
4. **Arquitetura de Dados (LAI) & Pipeline CRM:** Fluxo técnico de raspagem pública e quadro Kanban de gestão de leads salvos.

## Como publicar na Vercel
Basta subir este repositório no GitHub e importá-lo na Vercel como um projeto estático (Framework Preset: **Other**).
